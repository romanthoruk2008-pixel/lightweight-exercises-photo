# Стиль зображень вправ — v1

Версія: **v1**. Вимоги надані користувачем 2026-09-30 для пілоту з 5 вправ.
Статус: **поточна специфікація v1; користувач прийняв усі 25 конкретних PNG пілоту, simple-001 і simple-002**.
Дозвіл на пілот уже надано; повторно його не запитувати. Масова генерація не дозволена.

## Спільні вимоги

- Однакова модель людини в усьому каталозі: об’ємний 3D-анатомічний стиль **за прикріпленим еталоном**, незмінні пропорції й деталізація.
- Основні м’язи: цільовий колір **#F26445**. Допоміжні: той самий відтінок із легшою підсвіткою, приблизно **40–50% інтенсивності**. Підсвітка не робить тіло прозорим; без світіння чи загального помаранчевого відтінку.
- Квадратний **PNG**, ціль **1024×1024**, **справжній прозорий фон**; без білої/шахової підкладки.
- Людина безпосередньо виконує конкретну вправу. Показувати потрібне обладнання разом із нею, правильні опори, сидіння, руків’я, троси та точки контакту.
- Людину й необхідні частини обладнання не обрізати. Для вміщення у квадрат змінювати масштаб і ракурс, не спотворювати пропорції.
- Без тексту, рамок, інтерфейсу та декоративних предметів.
- Кількість поз і спосіб демонстрації руху визначити **за референсами**. Не додавати автоматично другу людину або кілька фаз.
- Техніку брати з англійського запису конкретного ID: опис, instructions, cues, mistakes, обладнання й м’язи. Не вигадувати насадки, конфігурацію чи положення тіла. Нерозв’язані суперечності → `needs_clarification`.

## Доступні референси (переглянуто один раз)

Пікселі шести вкладень доступні безпосередньо в історії цієї задачі. Локальні шляхи до оригінальних вкладень не надані; не вигадувати їх. Ролі після уточнення користувача: **лише зовнішність людини та 3D-анатомічний стиль**, не техніка чи конструкція обладнання.

| ID | Вкладення | Роль |
| --- | --- | --- |
| R1 | Похилий жим і підтягування в редакторі | модель/матеріали/деталізація |
| R2 | Cable Fly Crossovers | модель/матеріали/деталізація |
| R3 | Pendlay Row та моделі зі штангою | модель/матеріали/деталізація |
| R4 | Bench Press у макеті дизайну | основний орієнтир зовнішності |
| R5 | Triceps Rope Pushdown | анатомічна подача |
| R6 | Seated Shoulder Press | анатомічна подача |

Модель v1: атлетичний чоловічий анатомічний манекен із непрозорими сріблясто-сірими м’язовими поверхнями, без волосся на голові як у детальному R4/R3, у простих чорних шортах, босоніж; однакові пропорції, матеріал і рівень деталізації. Одна людина й одна характерна фаза конкретної вправи на одному PNG. Зелену шахову область редактора, білі картки, написи й UI не переносити. Палітра UI не визначає тіло/обладнання; основні й допоміжні м’язи кожного ID визначає каталог, а не підсвітка референсу.

Позу, хват, опори, обладнання та характерну фазу визначати за англійським текстом каталогу. За відсутності бренду використовувати стандартну конструкцію, сумісну з описом; фото тренажера не вимагати. Старі PNG/вихідні картинки вправ не використовувати як референси. Для послідовності моделі можна використати новий PNG пілоту як опору **лише зовнішності**, без перенесення пози/обладнання/м’язів і без припущення схвалення користувачем.

Cable Fly: стандартний стоячий двобічний горизонтальний fly із блоками на рівні грудей/плечей та окремими D-руків’ями; умовний текст про chest support не вимагає додаткової грудної опори. Це сумісне рішення сцени за дозволом користувача, а не техніка, скопійована з картинки. Рішення і конкретний prompt зберігати в progress.

Кожна фактична спроба пілоту має `style_version = v1` у progress і журналі. Зміна специфікації створює нову версію; прийняті результати не перегенеровувати без запиту. Усі п’ять конкретних файлів пілоту прийняті користувачем, включно з Shoulder Press attempt-3; це не дозвіл на масову генерацію.
# Вузьке уточнення для правки Shoulder Press

Після перегляду пілоту користувач прийняв перший Bench Press, Bicep Curl, Cable Fly та Ab Wheel. Це рішення щодо конкретних файлів; версія стилю залишається v1.

Два нові скриншоти з повідомлення про правки показують нижню й верхню фази Shoulder Press. Їхні пікселі доступні. Для прямо замовленої корекції вони задають цілісну конструкцію тренажера: стійка з ваговим стеком, сидіння та спинка, з’єднані важелі з руків’ями і стійка основа. Не переносити UI, білу підкладку, зачіску або м’язову підсвітку зі скриншота. Людина, матеріали та пропорції — v1; техніка й м’язи — англійський запис каталогу. Одне зображення з однією людиною в одній фазі, без колажу.
